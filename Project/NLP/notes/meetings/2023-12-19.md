제목에서 단어의 빈도로 중요도를 설정하면 정말 중요한 특정 키워드에 대한 정보가 손실될 수 있음

ex) 김혜자라는 인물 문서의 김혜자 도시락이라는 내용은 유명한 밈이고 중요도가 높다고 생각할 수 있는데 단순히 단어 빈도로 측정한 중요도에서는 그 순위가 매우 낮게 책정되어 필터링 과정에서 제거될 것

→ 어떻게 처리할까?

1. GPT API에 특정 문서를 참고해서 답변할 수 있게 하는 기능을 사용할 수 있는지 확인하기
2. 특정 키워드에 대해서 처리할 수 있도록 하기<br>ex) 사용자가 김혜자 도시락이라는 표현을 입력 → 인물 문서에서 키워드를 찾은 후 해당 내용이 포함된 항목을 바탕으로 답변을 하도록 프롬프트를 구성

대화 내용 기억(멀티턴) 구현은?

API에서 처리 가능할텐데 조금 더 알아봐야 함.

아니면 기존 대화 내용을 계속해서 요약한 후 프롬프트로 입력하는 방법도 있을 듯

#### 새로 구현해야 하는 기능

1. 테이블 파싱<br>2. 나무위키에서 관련 문서(다른 링크)에 접근하는 기능<br>3. 프롬프트에 포함되지 않은 기능이 탐지되면 문서에 다시 접근해서 관련 항목을 가져오는 기능
